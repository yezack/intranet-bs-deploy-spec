# 1. 适用范围、目标与技术边界

> 内网 B/S 架构开发规范 v2.4 · 第 1 章 ｜ [返回总览](../readme.md) ｜ 下一章：[§2 目标架构](02-目标架构.md)

**【强制】** 本规范适用于在互联网环境开发、最终要迁移进内网服务器运行的 B/S 架构系统。

**【强制】** 迁移目标是**无缝迁移**：内网部署不得要求现场编译、不得要求访问公网、不得要求修改代码，仅允许修改配置文件（`.env`）。

**【强制】** 必要条件为内网 Linux 虚拟机（**x86_64**）。基础镜像、共享数据库、统一网关等由运维在虚拟机基础环境中统一提供（见 [§2.1 部署拓扑](02-目标架构.md)），开发方不得在项目中重复定义。

**【强制】** **开发启动前**必须向运维确认本项目的对外域名，并写入 `.env.example` 的 `SITE_DOMAIN`（见 [§4.2](04-端口路径与网关接入.md)）；域名由运维分配，开发方不得自行编造。未确认域名不得开工——交付前闸门 `tools/preflight.sh` 也会因此拒绝打包。

**【强制】** 内网环境**没有外网出口**。运行期不得依赖任何公网资源，包括但不限于：CDN 引入的 JS/CSS、Google Fonts 等外网字体、外网图标库、外网地图/验证码/统计服务、外网 pip/npm 源。前端构建产物必须是自包含的。

## 1.1 技术边界

> 技术选型本身是【推荐】级，不锁死；但下表几条是必须满足的**硬性边界**。

**【推荐】** 后端使用 **Python + FastAPI**，前端使用 **Vue 3 或 React** 等现代框架。本规范**不锁定具体小版本**，但要求：

| 项 | 要求 |
|---|---|
| Python 基础镜像 | 固定 `python:3.<次版本>-slim`（如 `python:3.13-slim`），**禁止**用 `python:latest` 作基础镜像 |
| 前端构建 | Vite / 同类工具均可；构建产物统一为 `frontend/dist/` |
| 接口文档 | 生产环境默认关闭 `/docs`（内网也需要收敛攻击面），如需开启须在交付说明中写明 |
| 依赖来源 | 构建期使用国内镜像源；运行期零公网依赖（见本章第一条【强制】） |
| 目标浏览器 | 以现场实际浏览器为准（信创/内网常见 Chromium 86 级内核）；前端构建的 `target` 必须覆盖该基线 |

**【强制】** 前端构建产物必须**预构建后打进镜像**。内网服务器上不得执行 `npm install` / `npm run build`。
